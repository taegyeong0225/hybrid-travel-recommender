# 11주차 이미지 매핑 문제 해결

## 📋 문제

메인 페이지의 장소 카드에 이미지가 전혀 표시되지 않는 문제가 발생했습니다.

- **증상**: 모든 장소 카드에서 이미지가 로드되지 않음
- **현황**: `backend/app/ml/image_map.json` 파일에 3,114개의 장소-이미지 매핑 데이터가 존재하지만 활용되지 않음
- **영향**: 사용자 경험 저하, 추천 여행지의 시각적 정보 부재

## 🔍 원인 분석

### 1. 백엔드 API 응답에 이미지 경로 미포함
- `backend/app/ml/recommender.py`에서 추천 결과를 반환할 때 `image_url` 필드가 없었음
- `image_map.json` 파일이 존재하지만 로드 및 활용 로직이 구현되지 않음

### 2. Static 파일 서빙 설정 부재
- FastAPI에서 static 파일을 제공하는 설정이 없었음
- `/static/` 경로로 이미지 파일 접근 불가

### 3. 프론트엔드의 잘못된 이미지 경로
- `frontend/src/TravelCarousel.jsx`에서 하드코딩된 경로 사용
- 백엔드 API로부터 받은 이미지 경로를 활용하지 않음

```jsx
// 기존 코드 (문제)
src={`/images/${encodeURIComponent(place.name)}.jpg`}
```

## ✅ 해결 방안

### 1. 백엔드: image_map.json 로딩 및 활용

**파일**: `backend/app/ml/recommender.py`

```python
import json
import os

class TodayRecommender:
    def __init__(self, df: pd.DataFrame, weather_api_key: str):
        self.df = df
        self.weather_api = WeatherAPI(weather_api_key)
        self.context_booster = ContextBooster()
        self.image_map = self._load_image_map()  # 추가

    def _load_image_map(self) -> dict:
        """image_map.json 파일 로딩"""
        try:
            image_map_path = os.path.join(os.path.dirname(__file__), 'image_map.json')
            with open(image_map_path, 'r', encoding='utf-8') as f:
                return json.load(f)
        except Exception as e:
            print(f"Warning: Failed to load image_map.json: {e}")
            return {}
```

### 2. 백엔드: 추천 결과에 image_url 필드 추가

**파일**: `backend/app/ml/recommender.py`

```python
def _format_output(self, df: pd.DataFrame, weather_dict: dict) -> dict:
    # ...
    for i, row in df.iterrows():
        name = row.get('VISIT_AREA_NM', '') or ''
        # 이미지 경로 가져오기

        recommendations.append({
            'rank': i + 1,
            'name': name,
            'poi_id': str(poi_id) if poi_id else name,
            'type': self._get_type_name(type_cd),
            'region': region,
            'score': round(final_score, 3),

            'context_score': round(context_score, 3),
            'avg_rating': round(avg_rating, 2),
            'is_trending': trending_score > 0.5,
            'image_url': image_url  # 추가
        })
```

### 3. 백엔드: Static 파일 서빙 설정

**파일**: `backend/app/main.py`

```python
from fastapi.staticfiles import StaticFiles

# Static Files 마운트
static_dir = os.path.join(os.path.dirname(os.path.dirname(__file__)), "static")
if os.path.exists(static_dir):
    app.mount("/static", StaticFiles(directory=static_dir), name="static")
    logging.info(f"Static files mounted from: {static_dir}")
else:
    logging.warning(f"Static directory not found: {static_dir}")
```

### 4. 프론트엔드: 백엔드 이미지 URL 사용

**파일**: `frontend/src/TravelCarousel.jsx`

