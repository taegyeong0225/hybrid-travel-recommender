# 11주차 디자인 리팩토링

## 문제

### 1. 일관성 없는 디자인 스타일
- 각 페이지(로그인, 회원가입, 메인)마다 다른 색상 테마와 스타일을 사용
- 네비게이션 바와 페이지 간 시각적 일관성 부족
- 버튼, 입력 필드, 카드 등의 UI 컴포넌트가 통일되지 않은 스타일

### 2. 마이페이지 부재
- 사용자가 자신의 즐겨찾기와 방문한 장소를 확인할 수 있는 페이지가 없음
- 사용자 프로필 정보를 볼 수 있는 화면이 없음
- 사용자 경험(UX)이 불완전함

### 3. 사용자 인증 상태 관리 미흡
- 페이지 새로고침 시 로그인 상태가 유지되지 않음
- localStorage에 토큰이 있어도 자동 로그인이 되지 않음
- 네비게이션 바에 사용자 정보가 제대로 표시되지 않음

### 4. 로그인/회원가입 폼 정렬 문제
- 입력 폼이 화면 중앙에서 오른쪽으로 쏠려있음
- 입력 필드가 기울어져 보이는 시각적 문제
- 반응형 디자인이 제대로 적용되지 않음

## 원인

### 1. 디자인 일관성 부족의 원인
```css
/* 문제: 각 페이지마다 다른 색상 사용 */

/* Login.css */
background: linear-gradient(120deg, #ffffff 0%, #bcd8fd 100%);
background-color: #1E3A8A;

/* Signup.css */
background: linear-gradient(135deg, #f8fbff 0%, #e8f0ff 100%);
background-color: #1e3a8a;

/* App.css */
background: linear-gradient(90deg, #4f7cff, #a2c2f5);
color: #333;
```

**근본 원인**:
- 프로젝트 초기에 디자인 시스템이나 색상 팔레트를 정의하지 않음
- 각 컴포넌트를 개별적으로 개발하면서 스타일이 분산됨
- CSS 변수나 테마 시스템을 사용하지 않음

### 2. 마이페이지 부재의 원인
- 초기 개발 시 핵심 기능(추천 시스템)에 집중하여 사용자 프로필 페이지를 구현하지 않음
- 백엔드에는 사용자 데이터 API(`/api/auth/me`, `/api/favorites`, `/api/visited`)가 이미 구현되어 있었으나, 프론트엔드에서 활용하지 못함

### 3. 인증 상태 관리 미흡의 원인
```javascript
// App.jsx - 문제 코드
const fetchCurrentUser = async (token) => {
  // eslint-disable-next-line no-unused-vars 로 주석 처리됨
  // 실제로 호출되지 않음
}

useEffect(() => {
  // 토큰 확인 로직이 없음
  loadRecommendations();
}, []);
```

**근본 원인**:
- 앱 초기 로드 시 localStorage의 토큰을 확인하지 않음
- `fetchCurrentUser` 함수가 정의되어 있으나 실제로 호출되지 않음
- 사용자 인증 상태를 확인하는 로직이 useEffect에 포함되지 않음

### 4. 폼 정렬 문제의 원인
```css
/* 문제 코드 */
.input-group input {
  width: 100%;
  padding: 14px 16px;
  /* box-sizing이 정의되지 않음 */
  /* display 속성이 명시되지 않음 */
}

.login-box {
  width: 420px;
  /* box-sizing이 정의되지 않음 */
  /* padding이 width에 포함되지 않아 전체 너비가 420px + 80px = 500px이 됨 */
}
```

**근본 원인**:
- CSS box model에 대한 이해 부족
- `box-sizing: border-box`를 설정하지 않아 padding과 border가 width에 포함되지 않음
- 입력 필드가 inline 요소처럼 동작하여 정렬 문제 발생

### 2. 마이페이지 구현

#### 2.1 MyPage.jsx 생성
```jsx
function MyPage() {
  const [user, setUser] = useState(null);
  const [favorites, setFavorites] = useState([]);
  const [visited, setVisited] = useState([]);
  const [activeTab, setActiveTab] = useState('favorites');

  useEffect(() => {
    const fetchUserData = async () => {
      const token = localStorage.getItem('token');
      if (!token) {
        navigate('/login');
        return;
      }

      // 사용자 정보 가져오기
      const userResponse = await fetch('/api/auth/me', {
        headers: { 'Authorization': `Bearer ${token}` }
      });
      const userData = await userResponse.json();
      setUser(userData);

      // 즐겨찾기 가져오기
      const favResponse = await fetch('/api/favorites', {
        headers: { 'Authorization': `Bearer ${token}` }
      });
      const favData = await favResponse.json();
      setFavorites(favData);

      // 방문한 곳 가져오기
      const visitedResponse = await fetch('/api/visited', {
        headers: { 'Authorization': `Bearer ${token}` }
      });
      const visitedData = await visitedResponse.json();
      setVisited(visitedData);
    };

    fetchUserData();
  }, [navigate]);

  return (
    <div className="mypage-container">
      {/* 사용자 프로필 헤더 */}
      <div className="mypage-header">
        <div className="profile-avatar">
          {user.name.charAt(0).toUpperCase()}
        </div>
        <h1>{user.name}님의 여행 기록</h1>
        {/* 통계 카드 */}
        <div className="stats-grid">
          <div className="stat-card">
            <div className="stat-number">{favorites.length}</div>
            <div className="stat-label">즐겨찾기</div>
          </div>
          <div className="stat-card">
            <div className="stat-number">{visited.length}</div>
            <div className="stat-label">방문한 곳</div>
          </div>
        </div>
      </div>

      {/* 탭 컨텐츠 */}
      <div className="mypage-content">
        <div className="tabs">
          <button onClick={() => setActiveTab('favorites')}>
            즐겨찾기 ({favorites.length})
          </button>
          <button onClick={() => setActiveTab('visited')}>
            방문한 곳 ({visited.length})
          </button>
        </div>
        {/* 장소 카드 그리드 */}
      </div>
    </div>
  );
}
```

### 3. 사용자 인증 상태 관리 개선

#### 3.1 App.jsx 수정
```jsx
// 수정 전
const fetchCurrentUser = async (token) => {
  // eslint-disable-next-line no-unused-vars
  // 호출되지 않음
}

useEffect(() => {
  loadRecommendations();
}, []);

// 수정 후
const fetchCurrentUser = async (token) => {
  try {
    const response = await fetch('/api/auth/me', {
      headers: { 'Authorization': `Bearer ${token}` }
    });
    if (response.ok) {
      const userData = await response.json();
      setCurrentUser(userData);
    } else {
      // 토큰이 유효하지 않으면 로그아웃
      handleLogout();
    }
  } catch (error) {
    console.error("Failed to fetch user", error);
    handleLogout();
  }
};

useEffect(() => {
  let isMounted = true;

  const loadData = async () => {
    // 로그인 상태 확인
    const token = localStorage.getItem('token');
    if (token && isMounted) {
      await fetchCurrentUser(token);
    }

    // 추천 데이터 로드
    if (!didFetch.current && isMounted) {
      await fetchRecommendations();
      didFetch.current = true;
    }
  };

  loadData();

  return () => {
    isMounted = false;
  };
}, []);
```

**개선 사항**:
- 앱 로드 시 localStorage의 토큰을 확인하고 자동 로그인
- 토큰이 유효하지 않으면 자동 로그아웃 처리
- 사용자 정보를 전역 상태로 관리하여 모든 컴포넌트에서 접근 가능

**해결 원리**:
- `box-sizing: border-box`: padding과 border를 width에 포함시켜 실제 크기가 지정한 width와 일치
- `display: block`: input 필드가 블록 레벨 요소로 동작하여 수평 정렬 보장
- `width: 100%`: 부모 컨테이너의 전체 너비를 차지하여 일관된 정렬
- `margin: 0 auto`: 수평 중앙 정렬

## 개선 효과

### 1. 시각적 일관성
- 모든 페이지에 동일한 색상 테마 적용
- 브랜드 아이덴티티 강화
- 사용자 경험의 연속성 향상

### 2. 기능 완성도
- 마이페이지를 통해 사용자가 자신의 여행 기록을 관리할 수 있음
- 즐겨찾기와 방문한 곳을 시각적으로 확인 가능

### 3. 사용자 경험
- 자동 로그인으로 편의성 향상

- 토큰 만료 시 자동 로그아웃으로 보안 강화

### 4. 반응형 지원
- 모바일, 태블릿, 데스크톱 모든 화면 크기에서 최적화된 레이아웃
- 터치 인터페이스를 고려한 버튼 크기 조정
- 작은 화면에서도 가독성 유지

### 5. 코드 품질
- CSS box model을 올바르게 이해하고 적용
- 명확한 레이아웃 구조
- 유지보수가 쉬운 코드 구조

## 테스트 방법

### 1. 디자인 일관성 확인
```bash
# 프론트엔드 재시작
docker-compose restart frontend
```

1. 브라우저에서 각 페이지 방문
   - http://localhost:3000/ (홈)
   - http://localhost:3000/login (로그인)
   - http://localhost:3000/signup (회원가입)
   - http://localhost:3000/mypage (마이페이지, 로그인 필요)

2. 모든 페이지의 색상 테마가 보라색 그라데이션으로 통일되었는지 확인

### 2. 자동 로그인 확인
1. 로그인
2. 페이지 새로고침 (F5)
3. 로그인 상태가 유지되는지 확인
4. 네비게이션 바에 사용자 이름이 표시되는지 확인

### 3. 마이페이지 확인
1. 로그인 후 "마이페이지" 클릭
2. 사용자 프로필 정보가 표시되는지 확인
3. 즐겨찾기 탭과 방문한 곳 탭 전환 테스트
4. 빈 상태일 때 "여행지 둘러보기" 버튼 작동 확인

### 4. 폼 정렬 확인
1. 로그인/회원가입 페이지 방문
2. 입력 폼이 화면 중앙에 정확히 위치하는지 확인
3. 입력 필드가 수평으로 정렬되어 있는지 확인
4. 브라우저 창 크기를 조절하여 반응형 동작 확인

### 5. 반응형 디자인 확인
1. 브라우저 개발자 도구 열기 (F12)
2. 디바이스 도구바 활성화 (Ctrl+Shift+M / Cmd+Shift+M)
3. 다양한 화면 크기에서 테스트:
   - 모바일 (375px)
   - 태블릿 (768px)
   - 데스크톱 (1920px)
