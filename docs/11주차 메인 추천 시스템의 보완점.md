## 문제점 및 보완 필요 사항

### 1. 점수 다양성 부족 ⚠️

#### 문제
- **모든 추천 장소의 점수가 동일 (0.47점)**
- 20개 장소 모두 같은 점수로 순위 구분 불가
- 실질적으로 무작위 추천과 동일한 결과

#### 원인 분석
```python
# backend/app/ml/recommender.py:49-53
result['final_score'] = (
    0.5 * result['popularity_score'] +      # 0.4로 동일
    0.1 * result['trending_score'] +        # 0.0으로 동일
    0.4 * result['context_score']           # 0.675로 동일
)
```

**점수 구성**:
- `popularity_score`: 0.4 (모든 장소 동일)
- `trending_score`: 0.0 (트렌딩 아님)
- `context_score`: 0.675 (날씨/계절 점수 동일)

**최종 계산**:
```
0.5 × 0.4 + 0.1 × 0.0 + 0.4 × 0.675 = 0.47
```

#### 보완 방안
1. **인기도 점수 세분화**
   - 방문 횟수, 체류 시간, 재방문율 등을 고려한 상세 점수 계산
   - 정규화 방식 개선 (현재 단순 정규화로 차이가 없음)

2. **트렌딩 로직 개선**
   - 최근 급증한 방문 패턴 감지
   - 시계열 분석으로 인기 상승 추세 파악

3. **컨텍스트 점수 다양화**
   - 장소별 날씨 적합도 차별화
   - 계절별 매력도 점수 추가
   - 요일/시간대별 추천 가중치 적용

---

### 2. 장소 타입 편중 ⚠️

#### 문제
- **Top 20이 모두 "자연 관광지"**
- 문화 관광지, 쇼핑, 음식점 등 다른 타입이 없음

#### 보완 방안
1. **타입별 다양성 보장**
   ```python
   # 타입별 최소/최대 개수 제한
   type_distribution = {
       '자연 관광지': (5, 10),
       '문화 관광지': (3, 8),
       '레저/스포츠': (2, 5),
       '음식점': (2, 5),
       '쇼핑': (1, 3)
   }
   ```

2. **사용자 선호도 반영**
   - 과거 방문/찜 이력 기반 타입 선호도 학습
   - 개인화된 타입 가중치 적용

---

### 3. 지역 편중 ⚠️

#### 문제
- **경기도 (10곳), 강원도 (9곳), 인천 (1곳)**
- 서울, 부산, 제주 등 주요 관광지 제외
- 지역 다양성 부족

#### 보완 방안
1. **지역 다양성 알고리즘**
   - 최소 5개 이상 시도 포함 보장
   - 지역별 인구/관광객 수 고려한 할당

2. **사용자 위치 기반 추천**
   - GPS 또는 IP 기반 현재 위치 파악
   - 근거리 장소 우선 추천 (접근성)

---

### 4. 평점 신뢰도 문제 ⚠️

#### 문제
- **모든 장소가 평균 5.0점**
- 평점 데이터가 없거나 신뢰도가 낮음

#### 보완 방안
1. **평점 정규화**
   - 리뷰 개수를 고려한 가중 평점 (베이지안 평균)
   - 평점이 없는 경우 기본값 3.5점 적용

2. **리뷰 시스템 추가**
   - 사용자 리뷰 작성 기능
   - 별점 + 텍스트 리뷰 수집

---

### 5. 개인화 부재 ⚠️

#### 문제
- **모든 사용자에게 동일한 추천**
- 사용자 프로필, 이력, 선호도 미반영

#### 보완 방안
1. **협업 필터링 (Collaborative Filtering)**
   - 유사한 취향의 사용자가 좋아한 장소 추천
   - User-based 또는 Item-based CF

2. **콘텐츠 기반 필터링 (Content-based Filtering)**
   - 사용자가 좋아한 장소의 특성 분석
   - 유사한 특성의 장소 추천

3. **하이브리드 추천**
   - 협업 + 콘텐츠 + 컨텍스트 결합
   - 각 방식의 장점 활용

**개선 방향**:
```python
def calculate_popularity(self):
    # 다양한 지표 종합
    metrics = {
        'visit_count': self._get_visit_count(),           # 방문 횟수
        'avg_duration': self._get_avg_duration(),         # 평균 체류 시간
        'revisit_rate': self._get_revisit_rate(),         # 재방문율
        'rating_score': self._get_weighted_rating(),      # 가중 평점
        'recent_trend': self._get_recent_trend()          # 최근 트렌드
    }

    # 가중 합산
    popularity = (
        0.3 * metrics['visit_count'] +
        0.2 * metrics['avg_duration'] +
        0.2 * metrics['revisit_rate'] +
        0.2 * metrics['rating_score'] +
        0.1 * metrics['recent_trend']
    )
    return popularity
```

### 2. 다양성 보장 알고리즘 (MMR)

```python
def diversify_recommendations(candidates, top_n=20):
    """Maximal Marginal Relevance로 다양성 확보"""
    selected = []
    remaining = candidates.copy()

    # 1순위는 최고 점수
    selected.append(remaining.iloc[0])
    remaining = remaining.iloc[1:]

    while len(selected) < top_n:
        max_mmr = -1
        best_idx = None

        for idx, candidate in remaining.iterrows():
            # 관련성 (점수)
            relevance = candidate['final_score']

            # 다양성 (이미 선택된 것과의 차이)
            diversity = min([
                calculate_diversity(candidate, selected_item)
                for selected_item in selected
            ])

            # MMR = λ × relevance - (1-λ) × diversity
            mmr = 0.7 * relevance + 0.3 * diversity

            if mmr > max_mmr:
                max_mmr = mmr
                best_idx = idx

        selected.append(remaining.loc[best_idx])
        remaining = remaining.drop(best_idx)

    return selected
```

### 3. 개인화 추천 (협업 필터링)

```python
from scipy.sparse import csr_matrix
from sklearn.neighbors import NearestNeighbors

class CollaborativeFilter:
    def __init__(self, user_place_matrix):
        self.matrix = csr_matrix(user_place_matrix)
        self.model = NearestNeighbors(metric='cosine', algorithm='brute')
        self.model.fit(self.matrix)

    def recommend_for_user(self, user_id, n=20):
        # 유사 사용자 찾기
        distances, indices = self.model.kneighbors(
            self.matrix[user_id],
            n_neighbors=10
        )

        # 유사 사용자들이 좋아한 장소
        similar_users = indices.flatten()[1:]
        recommended_places = []

        for similar_user in similar_users:
            places = get_user_favorites(similar_user)
            recommended_places.extend(places)

        # 빈도 기반 정렬
        from collections import Counter
        place_counts = Counter(recommended_places)
        return place_counts.most_common(n)
```

## 성능 지표 정의

추천 시스템 개선을 측정하기 위한 KPI:

### 1. 정확도 지표
- **CTR (Click-Through Rate)**: 추천 클릭률
- **Conversion Rate**: 찜/체크인 전환율
- **Session Duration**: 평균 세션 시간

### 2. 다양성 지표
- **Coverage**: 전체 장소 중 추천된 비율
- **Novelty**: 비인기 장소 추천 비율
- **Serendipity**: 예상 밖 만족도

### 3. 개인화 지표
- **Personalization Score**: 사용자별 추천 차이도
- **User Satisfaction**: 사용자 만족도 점수

## 결론

현재 TripMate 추천 시스템은 기본적인 컨텍스트 기반 추천을 제공하고 있으나, **점수 다양성 부족**과 **개인화 부재**가 주요 한계점입니다.

### 단기 개선 (1-2주)
1. 인기도 점수 계산 로직 정교화
2. 타입/지역 다양성 보장 알고리즘 추가

### 중기 개선 (1-2개월)
1. 사용자 프로필 기반 개인화
2. 협업 필터링 모델 구현
3. 리뷰 시스템 추가

### 장기 개선 (3-6개월)
1. 딥러닝 기반 하이브리드 추천
2. 실시간 트렌드 감지
3. A/B 테스트 프레임워크 구축

이러한 개선을 통해 사용자에게 더 개인화되고 다양한 여행지 추천을 제공할 수 있을 것입니다.
